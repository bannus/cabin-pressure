# Core pillars

## Readable chaos

Start with obvious tactical decisions, then let simple interacting systems create
escalation: bladder meters, queues, carts, blockers, turbulence, and lavatory
capacity.

## Physical comedy through logistics

The cabin is a constrained traffic network. Seats, rows, aisle cells, queues,
stand-up time, sit-down time, carts, and turbulence should create bottlenecks
that are readable and funny.

## Individual control, group consequences

Commands target individual passengers, but each command can affect blockers,
cooldowns, aisle space, lavatory queues, and turbulence risk.

## Fast configurable experiments

The engine should answer tuning questions quickly: fill rates, lav duration,
initial urgency, cart disruption, turbulence timing, level length, and aircraft
layout should be pure data.
