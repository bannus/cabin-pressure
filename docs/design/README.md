# Cabin Pressure design docs

This directory splits the original prototype brief into focused sub-documents.

## Prototype direction

Build a deterministic, data-driven TypeScript simulation core first, then layer a
browser debugger/playtest UI on top. Mobile shells can come later after the core
game loop proves fun.
